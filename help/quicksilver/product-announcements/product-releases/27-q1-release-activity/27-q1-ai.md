# Miglioramenti dell’intelligenza artificiale nel primo trimestre 2027

Questa pagina descrive i miglioramenti dell’intelligenza artificiale apportati con la versione del primo trimestre 2027 all’ambiente di anteprima. Tali miglioramenti saranno resi disponibili nell’ambiente di produzione come indicato.

Per un elenco di tutte le modifiche disponibili al momento nel ciclo di rilascio del primo trimestre 2027, consulta [Panoramica sulla versione del primo trimestre 2027](/help/quicksilver/product-announcements/product-releases/27-q1-release-activity/27-q1-release-overview.md).

## Set di strumenti del server Workfront MCP

>[!NOTE]
>
>Anteprima: 21 ottobre 2026
>Versione rapida di produzione: 12 novembre 2026
>Produzione per tutti: 21 gennaio 2027

Per semplificare il controllo delle funzionalità di Workfront a cui un client di intelligenza artificiale può accedere, abbiamo aggiunto degli strumenti al server Workfront MCP. Invece di esporre l’elenco completo degli strumenti autorizzati, ora puoi limitare il catalogo MCP alle funzionalità richieste dal cliente. I set di strumenti disponibili includono `core`, `comment-stream`, `planning` e `approvals`.

La disponibilità degli strumenti ora riflette più chiaramente le adesioni ai prodotti. Per i clienti con licenza solo per Workfront Planning vedere Strumenti di pianificazione, per i clienti con licenza solo per Workfront Workflow vedere Strumenti di workflow e per i clienti con licenza per entrambi vedere entrambi i set.

Per ulteriori informazioni, vedere [Configurare il server Adobe Workfront MCP](/help/quicksilver/workfront-basics/workfront-mcp-server/configure-workfront-mcp-server.md) e [Utilizzare il server Adobe Workfront MCP](/help/quicksilver/workfront-basics/workfront-mcp-server/use-workfront-mcp-server.md).
